# catering-ai

正斗粤厨 · AI 行业落地学习项目（苏德忠）

本仓库用于练习与沉淀「AI 行业落地专家」转型路径中的工程能力：
FastAPI 服务、数据清洗、LLM 应用、Agent 工作流等。

## 环境

- Python 3.13（虚拟环境 `./.venv`）
- 激活：`source .venv/bin/activate`
- 安装依赖：`pip install -r requirements.txt`

## 目录结构（逐步演进）

```
catering-ai/
├── .gitignore
├── README.md
├── src/            # 业务代码
└── tests/          # 测试
```

## 运行

```bash
source .venv/bin/activate
python -m src.main
```

> 更多接口与部署说明将在后续迭代中补充。
